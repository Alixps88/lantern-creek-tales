Privacy Policy

Lantern Creek Studio · effective October 19, 2026

Lantern Creek Studio is a private publishing tool used only by the owner of the YouTube channel Lantern Creek Tales to manage that channel. It is not offered to the public, and no one else signs in to it.

What the tool accesses

With the channel owner's permission, granted through Google sign-in, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload the channel's own videos as private, with their titles, descriptions, thumbnails, captions and playlists;
  • read the channel's own public identity and performance statistics.

It does not access any other channel, any viewer's personal data, Gmail, contacts or any other Google service.

Storage and sharing

The access token is stored only in the macOS Keychain on the owner's own computer. Channel statistics are kept only on that computer. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also follows the YouTube Terms of Service; see the Google Privacy Policy for how Google handles data.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it deletes the tool's ability to reach the channel, and the stored token can be removed from the Keychain.

Viewers

People who watch Lantern Creek Tales on YouTube are covered by Google's privacy policy. This tool collects nothing from them.

Contact

Questions can be sent through the channel's About page.
